# Исторический глобус

Статическая версия глобуса для GitHub Pages. Аккаунт ChatGPT для посещения не требуется.

## Публикация

Создайте репозиторий с основной веткой `main`, загрузите файлы этого проекта.
В Settings → Pages выберите Source → GitHub Actions и запустите workflow
Publish historical globe. Адрес опубликованного сайта появится в Pages и в результате workflow.
Для GitHub Free нужен публичный репозиторий. Сборка учитывает подпапку репозитория
и собственный домен через настройку `base_path` GitHub Pages.

## Локальная сборка

Требуется Node.js. Выполните `node scripts/build-pages.mjs`; результат — `_site/`.
Для проверки подпапки: `BASE_PATH=/history-globe node scripts/build-pages.mjs`.

## Источники и ограничения

Основа: публичная клиентская версия Panchronia от 15 октября 2026 года с изменениями интерфейса.
Исходное авторство, ссылки на источники, лицензии карт и сведения об изображениях сохраняются.
Контакт для предложений: https://t.me/TimZaynullin.
Этот проект не предоставляет дополнительных прав на материалы третьих лиц.

Исторические данные, границы, 1587 карточек государств, JavaScript и шрифты размещаются
вместе с сайтом. Изображения Wikimedia и ссылки на статьи остаются внешними.
Авторизация и чат исходного сервера не реализованы. Доступность GitHub Pages
и внешних материалов зависит от сети посетителя.
